# Privacy Policy

**Last Updated:** October 1, 2026

Droid Vault is an open-source Android utility focused on local backup, restore, migration, and
system management.

## Privacy

* **Your data stays on your device.** Droid Vault does not intentionally collect, sell, or upload
  your personal data to its own servers.
* **Local processing.** SMS, call logs, contacts, app data, Wi-Fi/Bluetooth data, media, and other
  backup data are processed locally when you use the corresponding features.
* **Temporary permissions.** Unlike many apps that retain sensitive permissions, Droid Vault is
  designed to grant required permissions only when they are needed for an operation and **revoke
  temporary permissions as soon as the task is completed**, where technically possible.
* **No account required.** Droid Vault does not require an account or registration.
* **Root access.** Some features require root access to perform system-level operations. Root access
  is only used for the operations you request.
* **No network access.** Droid Vault does not request the INTERNET permission. It makes no network
  connections and cannot send data anywhere; everything is processed and stored on your device.
* **You control your backups.** Backup files are stored locally in locations you choose. You are
  responsible for protecting or deleting copies you create or share.
* **Backups are not encrypted.** Vault archives (`.shift` files) and the automation state file are
  stored as-is so that any root tool or recovery can read and restore them — they are **not**
  encrypted, and `.shift` archives can contain sensitive data such as messages, call logs, Wi-Fi
  credentials, Bluetooth pairings and per-app data. Anyone with access to the backup folder (or the
  SD card itself) can read them. Protect the folder with device encryption and a screen lock, and
  delete backup copies you no longer need. An opt-in encrypted-vault mode is a planned enhancement;
  until then, treat a Droid Vault backup exactly like the data it contains.

## Changes

This policy may be updated when Droid Vault's functionality or data handling changes.
